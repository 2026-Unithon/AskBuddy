## 앱 전체 규칙

- **중간점(·) 금지.** 화면에 보이는 모든 글에서 뺀다(G4 메모). 개수는 숫자 뱃지, 나열은 쉼표나 줄바꿈, 메타 정보는 간격으로 나눈다.
- **말은 짧게.** "정리 끝난 자료 1건 · 확인하기" 대신 "정리 끝!"(o03c). 명령조 대신 일 맡은 직원이 부탁하는 말투(o04a: "카드가 준비됐어요! 검수 부탁드려요!").
- **설명용 회색 문구는 기본으로 넣지 않는다.** "제목은 메뉴·업무 이름이에요", "사용자 카테고리", "공통 + 담당 근무조 할 일을 봐요" 같은 안내는 지운다(o06a, o06e, o13c, o16a, o17a, o17b, s02b, s03b).
- **읽는 화면과 고치는 화면을 나눈다.** 카드 상세는 읽기 전용, 오른쪽 위 '수정하기'로 들어가야 드래그·길게 누르기·삭제가 된다(o06d, o06f).
- **주 행동은 버튼 하나, 보조 행동은 작은 글자 버튼.** '검수 완료' 버튼 + '나중에 하기' 작은 글자(o04c), '수정 완료' 버튼 + '수정하지 않고 돌아가기' 작은 글자(o08b).
- **다크패턴 금지(G6):** 죄책감 주는 문구, 끝없는 권유. 알림 켜기 권유는 '나중에' 누르면 다시 띄우지 않는다.
- **로딩(G3):** 처음 불러올 때 스켈레톤, 저장·전송 버튼은 버튼 안 스피너, 파일 올리기는 진행 막대, 체크·토글처럼 되돌릴 수 있는 것은 낙관적 반영.
- **피드백(G4):** 되돌릴 필요 없는 완료는 토스트, 되돌릴 수 있는 완료는 스낵바(5초 되돌리기), 되돌릴 수 없는 일은 확인 창, 화면 전체 상태는 배너, 입력 칸 하나의 문제는 칸 아래 빨간 문구.
- **모션(G1·G2):** 앞으로 가면 오른쪽에서, 뒤로 가면 왼쪽에서 들어온다. 탭끼리는 페이드. 이즈 아웃 200~250ms. 누르면 0.97로 줄어든다. 상태가 바뀌는 것(체크·스위치)만 스프링.

## 화면별 결정

기법은 선택 페이지의 이름 그대로 적는다. 메모는 사용자 말을 정리했다.

### 사장님 오늘 매장 (계획 4)
- **o01a 헤더:** 뱃지, 툴팁, 코치마크.
- **o01b 근무조 현황:** 진행 바, 자이가르닉 효과(남은 수를 제목으로), 확대 전환.
- **o01c 기록 보기 버튼:** 선택 과부하. 큰 버튼을 없애고 현황 카드 안 링크로.
- **o01d 확인해 주세요:** 바텀시트로 바로 답하기, 프레이밍, 밀어서 '나중에', 순차 등장.
- **o01e 넣기 입력창:** 코치마크, 슬라이드(스크롤 내리면 숨김).
- **o01f 하단 탭:** 뱃지, 스프링.

### 사장님 넣기·정리·검수 (계획 2)
- **o02a 제목·예시:** 추천 질문 칩, 순차 등장.
- **o02b 입력창:** 파일 첨부(진행 막대·완료·실패), 로딩 버튼, 텍스트 필드 상태. 붙여 넣은 글은 지금 글자 수 제한이 없다. 제한을 두게 되면 크게, 불편하지 않게 보여준다.
- **o02c 종류 칩:** 선택된 칩은 진한 배경만. 한 줄로. 칩을 작게, 살짝 네모나고 모서리만 둥글게.
- **o03a 정리 중:** 에이전트 단계, 단계 표시, 스켈레톤.
- **o03b 파일별 상태:** 스피너, 페이드.
- **o03c 끝났을 때:** 토스트, 스낵바, 배너. 문구는 짧게 "정리 끝!".
- **o04a 일부 실패:** 배너, 인라인 오류. 화면 전체를 일 맡은 직원이 검수를 부탁하는 말투로. 제목 "카드가 준비됐어요! 검수 부탁드려요!"(지금 제목과 같은 글꼴). 실패 배너 문구 "처리하지 못한 자료가 있어요." 아래에 자료마다 이름과 이유를 한 줄씩(서버는 자료별 이유를 이미 저장한다).
- **o04b 나눈 카드 목록:** 순차 등장, 밀어서 삭제, 길게 누르기. '하나씩 봐 주세요' 삭제. 섹션 둘로: **"맞는지 확인해 주세요!"**(중복·충돌 등 이상한 것을 이유와 함께, 그 자리에서 바로 고치거나 지우기)와 **잘된 것**(아무것도 안 해도 된다는 느낌으로 모아 보기). 카드가 글 나열이 아니라 완성된 카드처럼 보이게. 중간점과 밑의 출처 글씨 삭제.
- **o04c 하단 버튼:** 로딩 버튼, 피크엔드. 버튼은 **'검수 완료'** 하나, 그 아래 작은 글자 **'나중에 하기'**. 완료하면 토스트 "지식이 추가됐어요".

### 사장님 카드 (계획 3)
- **o05a 검색·필터:** 세그먼트, 뱃지. 검색은 글자를 칠 때마다 바로 걸러진다. 필터는 **전체 / 공개 / 검수 필요 / 미공개**, 지운 카드는 보여주지 않는다. 뱃지는 '검수 필요'에만 빨간색.
- **o05b 다른 답 배너:** 배너 대신 '검수 필요' 안으로 넣고, 검수 카드마다 제안을 붙인다. 주황 대신 톤온톤이면서 눈에 띄는 색.
- **o05c 카드 목록:** 밀어서 삭제, 당겨서 새로고침, 공유 요소 전환. 밀기 규칙: 전체·공개에서 왼쪽 → 미공개, 전체·미공개에서 오른쪽 → 공개, 미공개에서 왼쪽 → 아예 삭제. 배치는 사용자 스케치대로: 카테고리마다 섹션 제목 + 굵은 밑줄, 그 아래 카드 격자 — 레시피 카테고리는 2열, 공지 등 나머지는 한 줄에 하나(2026-11-07 스케치). 카드에는 이름과 › 만. 공개·검수 필요·미공개는 글자가 아니라 모양과 색으로 구분하고, 공개 카드는 확실히 공개된 것처럼.
- **o06a 상세 헤더:** 바텀시트(카테고리 고르기). '제목은 메뉴·업무 이름이에요' 삭제.
- **o06b HOT/ICE:** 프레이밍. 근거 글자와 값 칩 삭제, 간결하게, 카드 느낌. '수치 · HOT' 같은 칩 대신 카드 밖에 굵고 조금 큰 글씨로 'HOT'.
- **o06c 근거:** 줄마다 근거 삭제. 페이지 맨 아래 마지막 카드 밑에 아주 작은 회색 글씨로 근거 자료 목록.
- **o06d 순서·메모 블록:** 칩 삭제, 근거는 o06c와 같이. 드래그·길게 누르기는 수정하기 안에서만.
- **o06e 근무조 할 일:** 스위치. '오늘 할 일에 넣기' → '공통'. 그 아래 사장님이 만든 근무조(오픈·미들·마감…)가 각각 스위치. 회색 안내 삭제.
- **o06f 고치기·지우기:** 두 버튼 삭제. 오른쪽 위 '수정하기'. 수정 화면 아래 '수정 완료'(초록, 왼쪽) / '돌아가기'(흰색, 오른쪽) 좌우 배치. 수정 완료하면 스낵바 "수정 완료 · 되돌리기"(5초).
- **o07a 확인 필요 사유:** 라디오, 인라인 오류. 사유 가독성 개선, '근거 보기 1' 삭제.
- **o07b 버튼:** 로딩 버튼, 토스트. '공개' / '미공개' 좌우 배치.
- **o08a 비교:** 프레이밍(바뀐 부분만 강조).
- **o08b 버튼:** '수정 완료' 하나만, 아래 작은 회색 글자 '수정하지 않고 돌아가기'.

### 사장님 질문 (계획 4)
- **o09a:** 세그먼트. **o09b:** 순차 등장, 바텀시트, 사회적 증거. **o09c:** 이 화면은 탭 없음.
- **o10a:** 사회적 증거, 확대 전환. **o10b:** 선택 과부하, 파일 첨부(입력창 안 📎). **o10c:** 로딩 버튼, 피크엔드, 텍스트 필드 상태.

### 사장님 설정·관리 (계획 4)
- **o12a 설정:** 뱃지, 프레이밍. 위쪽은 진짜 프로필처럼, 연필 아이콘으로 수정. 아래는 관리 항목 나열.
- **o12b·s07b 로그아웃:** 확인 창.
- **o13a 기록 보기:** 바텀시트, 셀렉트. 사장님 자신은 빼고 알바생만. 위 문구 바꾸기('내 기록' 아님). 출퇴근 기록 기능과 합쳐질 예정(별도 기획).
- **o13b 달력:** 날짜 선택, 스와이프, 바텀시트.
- **o13c 기록 남기기 토글:** 사장님 화면에서는 삭제(알바생 전용). 회색 설명 삭제.
- **o14a 근무조 카드:** 드래그, 바텀시트. '할 일 담기'를 초록 버튼으로.
- **o14b:** '근무조 추가' → '추가' 버튼 하나만. 직급 설정은 별도 기획.
- **o14c:** 토스트, 날짜 선택(시간 휠), 스위치.
- **o15a 초대:** 토스트, 프레이밍. '링크 복사'와 '카톡으로 보내기' 버튼을 다르게, 카톡 버튼은 카카오 마크와 카카오 디자인.
- **o15b 합류 승인:** 확인 창, 스낵바. 승인·거절 버튼 모양을 다르게.
- **o15c 내보내기:** 밀어서 삭제, 확인 창.
- **o16a 직원 담당:** 토스트, 체크박스, 낙관적 UI. 회색 안내 삭제.
- **o17a·o17b 카테고리:** 텍스트 필드 상태, 밀어서 삭제, 확인 창, 드래그. 설명 문구들 삭제. '추가' 글자 안 깨지게.
- **o18a 휴대폰 알림:** 배너, 코치마크. '허용하지 않아도…' 문구 삭제.
- **o18b 알림 목록:** 당겨서 새로고침과 새로고침 버튼 둘 다, 뱃지, 밀어서 읽음.
- **o19a 첫 준비 끝:** 피크엔드, 토스트. '직원 관리 · 합류 승인' → '직원 관리'.
