## 1. 이 제품이 무엇이고, 왜 이렇게 만들었나

카페 등 소규모 매장의 업무 인수인계를 AI가 대신한다. 점주가 음성·영상·카톡·문서를 올리면
지식카드가 되고, 신입은 로드맵과 채팅으로 배운다.

설계의 중심은 한 문장이다 — **승인된 매장 지식만 근거로 답하고, 근거가 없으면 추정하지 않고 점주에게 넘긴다.**

```
신입이 묻는다 → 지식에 없으면 "모른다"고 답한다 → 점주 폰에 알림
→ 점주가 30초 답한다 → 그 답이 매장의 영구 지식 → 다음 알바는 같은 질문을 하지 않는다
```

"모른다고 말하는 것"은 한계가 아니라 기능이다. 구현 우선순위가 충돌하면 **이 순환을 닫는 쪽**을 택한다.

이 원칙이 코드에 박힌 지점:

| 원칙 | 코드에서 |
|---|---|
| 근거 없으면 답하지 않는다 | `kind: "miss"` 면 답변 LLM 자체를 호출하지 않는다 |
| 인용 없는 답은 답이 아니다 | `ANSWERED` 메시지는 `message_citations` ≥ 1. 0건이면 답변을 폐기한다 |
| 생성은 하되 서버가 검증한다 | `validate_grounded_payload` 3종(인용 화이트리스트·숫자 부분집합·낱말 부분집합). 실패 시 `CARD_ORIGINAL` 폴백 (D12) |
| 검수 없이 공개되지 않는다 | 검색·학습은 `published_version_id` 있는 승인 카드만 본다 (D13) |

## 5. 절대 건드리지 않는 것

정본은 `CLAUDE.md` 다. 여기엔 **자주 어기게 되는 것**만 옮긴다.

1. **RLS 를 쓰지 않는다.** 매장 격리는 API 코드가 전부 책임진다.
   모든 DB 함수는 `store_id` 를 **필수 인자**로 받는다 — 기본값·`Optional` 금지.
   `WHERE store_id = ?` 없는 조회 쿼리를 쓰지 않는다. `store_id` 는 요청 본문이 아니라 **JWT** 에서 꺼낸다
2. **지식 진입점은 `POST /reg/retrieve` 하나다.** 채팅이든 검색이든 여기를 통과한다
3. **모델명·차원·임계값은 `api/app/config.py` 가 단일 출처.** 코드에 리터럴 금지
4. **임베딩은 `app.reg.embeddings.embed_texts` 하나만.** 새 임베딩 함수를 만들지 않는다 (D4).
   동기 함수이므로 async 문맥에서는 `asyncio.to_thread` 로 감싼다
5. **자동 재분류는 `assignment_type='MANUAL'` 카드를 덮지 않는다.** 사람이 옮긴 것이 우선이다
6. **`.env` 에 인라인 주석 금지.** dotenv 가 값에 주석을 붙여 읽는다
7. **사용자 화면에 '신뢰도 %' 를 쓰지 않는다.** `knowledge_cards.confidence` 는 점주 검수 정렬용 내부값이다.
   사용자에게는 '매장 지식 완성도'(필수 항목이 채워진 비율)를 쓴다
8. **서비스명은 AskBuddy 하나.** Relay·유니쉐프를 쓰지 않는다
9. `pip freeze > requirements.txt` 금지 — 한 줄씩 append
10. 인증 우회 엔드포인트를 만들지 않는다. 로컬 토큰은 `/auth/login` 또는 `api/scripts/dev_token.py --force`

하지 않기로 한 것: 별도 벡터 DB(pgvector로 충분), YOLO·SAM 등 CV 파이프라인, Supabase Realtime(D6),
`is_sensitive` 관련 로직(D5), 지식 그래프(`이관경계_실험설계.md` 6-6).

## 8. 자주 빠지는 함정

| 함정 | 실제로 일어나는 일 |
|---|---|
| `INGEST_MODE` 가 `mock` 인 걸 잊는다 | LLM 을 안 부르고 가짜 카드가 나온다. 기본값이 `mock` 이다 (D10) |
| 평가 수치가 100% 로 나온다 | `PROGRESS.md` 의 읽기 경로가 전부 100% 인 건 **골든셋이 8문항**이기 때문이다. 실력이 아니라 표본이다 |
| 한 번 돌려보고 좋아졌다고 판단 | 추출은 비결정적이다. 최소 3회 + 음성 대조군 (D17) |
| 두 가지를 한 번에 바꾼다 | 실험은 한 번에 하나씩. 어느 쪽이 효과였는지 영원히 모르게 된다 |
| `confidence` 를 화면에 띄운다 | 폐기된 지표다. 내부 정렬용 |
| 새 임베딩 함수를 만든다 | D4 위반. 차원·임계값 재측정이 필요해진다 |
| 문서 체크박스를 믿는다 | 3장 끝의 경고를 보라. 커밋이 앞서 있다 |
| 완료로 적는다 | 브라우저를 못 띄웠으면 그렇게 쓴다. 확인하지 않은 항목을 완료로 적지 않는다 |
