칸 설명
- **실행 id**: 앱 머리글자 + 번호(C=Claude, G=GPT, M=Gemini). 같은 자료 안에서만 유일하면 된다.
- **입력 형태**: 원본 그대로 / 이미지로 바꿔 첨부 / 일부 잘라 첨부 등 — 결과 차이의 원인이 된다.
- **지시문**: 조립 명령 그대로. 지시문을 손으로 고쳤으면 고친 내용을 적는다.
- **결과 위치**: 그 실행의 산출물 폴더. 아래 파일을 둔다.
  - `result.json` — 2부 JSON 그대로
  - `worklog.md` — 1부 작업 기록 + 실행 코드 + 3부 자기 점검 그대로
  - `captures/` — 화면 캡처(도구 실행 화면)
