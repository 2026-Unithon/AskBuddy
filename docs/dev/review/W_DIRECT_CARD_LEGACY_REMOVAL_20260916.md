# 직접 카드 추출 레거시 제거

2026-09-16 · 사용자 요청: 사용하지 않는 직접 카드 추출 프롬프트와 연결 코드를 삭제하거나 현재 흐름으로 교체.

현재 흐름은 원본 → `extract_facts` → 원장 선저장 → `assemble_cards` → 검수·승인이다.

## 변경

- 직접 카드 추출 프롬프트를 삭제했다. Git 이력의 기존 파일은 복원할 수 있다.
- dispatcher의 직접 추출 함수, Gemini의 직접 카드 추출/해당 프롬프트 렌더 함수,
  pipeline의 호출되지 않는 옛 구간별 카드 추출/reduce 함수를 제거했다.
- 옛 1패스/2패스 선택 설정을 제거했다. 영상 구간 분할 설정은 현재 사실 추출에서 계속 사용한다.
- 미리보기는 사실 추출 후 정식 등록과 같은 `assemble_assertions`를 호출한다.
  원장/카드 쓰기는 생략하고 카테고리·용어 읽기를 마친 뒤 DB 연결을 닫는다.
- mock도 합성 사실 추출 → 그 사실을 카드로 조립하는 두 단계를 사용한다.
  카드 mock을 사실로 역변환하는 코드는 제거했다. 카테고리가 없어도 사실은 추출되며 조립 불가를 표시한다.
- 새 평가 기록은 실제 사용하는 사실 추출/조립 프롬프트 두 해시와 고정 pipeline version을 기록한다.
  옛 설정/리포트는 덮어쓰지 않았다.
- 조립 지침은 같은 대상의 HOT/ICE/사이즈를 **한 카드 안의 규격별 행/구역**으로 표시하고
  각 fact/ref/값의 규격 연결을 유지하도록 교정했다. 2~3문장 강제 요약 제한도 제거했다.

카드 응답 DTO와 기존 카드 facts 저장은 현재 조립/화면에서도 쓰므로 유지했다.
레거시 직접 추출 경로의 제거가 현재 카드 API 계약 삭제를 뜻하지 않는다.
과거 review/인계 기록의 당시 코드 이름은 역사 기록으로 보존했다.

## 검증

- 전체 회귀 **434 tests / 80 subtests 통과**.
- 추가한 오프라인 호출 검증: real의 사실 추출/조립 프롬프트 입력 분리,
  mock 사실/카드 ref 연결, 동일 대상의 HOT/ICE 한 카드와 조건/예외/순서 보존,
  카테고리 없는 조립, 미리보기의 현재 흐름과 DB 읽기/연결 종료.
- 현재 app/scripts/tests에서 제거한 직접 추출 이름·옛 pass 옵션·옛 helper 참조 0건.
- 수정한 app 5개 파일의 매장 격리 AST 검사 위반 0건. compile 및 diff 공백 검사 통과.
  전체 ingest 폴더 검사에서 나온 15건은 수정하지 않은 repository의 기존 항목이며 이번 변경 파일에는 없다.
- 새 SQL/라우터/migration은 없다. 실제 DB 변경이나 유료 모델 호출은 실행하지 않았다.

수정한 프롬프트의 실제 모델 생성 품질/새 카드 공개 인수는 별도 검증이다.
