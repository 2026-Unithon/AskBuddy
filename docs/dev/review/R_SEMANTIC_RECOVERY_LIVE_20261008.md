## 구현과 검증

- 일반 의미 v8: `parts`가 1개여도 독립 항목의 해석·슬롯·승인 참조를 검증한 뒤 처리한다. 상위/하위 참조는 정확히 같아야 하며 혼합 해석이나 누락 ID 추정은 허용하지 않는다.
- 선택 승인 RAW의 각 줄과 typed 규칙을 서버 ID로 나눠 `rule_coverage`를 요구한다. 필수 규칙은 실제 상황 결론의 정확한 인용 구절과 같은 출처에 연결돼야 한다. 승인 원문에만 규칙이 있으면 결론 적용으로 인정하지 않는다. 규칙의 필수 여부와 의미 일치 판단 자체는 여전히 모델 판단이다.
- 허용된 일반 의미 오류 이후 사용자 원문을 매장·회원·세션으로 격리해 최대 24시간 보존한다. 다음 요청은 성공 발화와 실패 발화를 시간순으로 합쳐 최근 10개를 전달한다. 모델 실패 출력·가짜 성공 receipt·pending은 저장하지 않는다. 같은 요청 키의 본문 충돌, 다른 세션 조회, 오래된 이력 저장을 차단한다. 성공한 요청은 복구 목록에서 제외하고 만료 행을 정리한다.
- 실패 발화 저장은 최대 0.3초의 best effort다. 저장 실패 시 원래 API 오류를 유지하므로 모든 장애에서 문맥 복구를 보장하지는 않는다. 인증·DB·검색 실패나 선택/정책 요청은 이 복구 경로에 포함하지 않는다. 기존 중복 유료 호출 방지는 유지한다.

**배포 순서:** 새 `20261008120000_r_failed_user_turns.sql` migration을 API보다 먼저 적용해야 한다. 이번에는 격리 DB에만 적용했고 운영 DB·플래그는 변경하지 않았다.
