## 다음 보완 순서

1. 모델용 SelectedBlock schema에서 `fact_revision_ids`와 `raw_span_id`를 모두 명시하도록 요구한다. RAW는 `[]`와 실제 span ID, typed fact는 사실 ID 목록과 null을 반환하게 하고 서버의 둘 중 하나 검사도 유지한다. 공개 DTO를 느슨하게 하거나 서버가 누락 ID를 추정하지 않는다.
2. 검증 입력에 선택 근거 목록과 전체 후보 목록을 명시적으로 분리한다. `checked_*`는 선택 근거만, `candidate_coverage`는 후보 전체라는 설명과 모델용 필드 설명을 강화한다. 장기적으로 중복 ID 전사를 줄이는 작은 참조 키 계약도 검토한다.
3. 이번 실제 실패 JSON을 회귀 자료로 보존하고 전송 schema·서버 검사·API 거절 경로를 먼저 무료로 검증한다.
4. 이후 별도 버전·상한을 고정한 소수 실제 호출로 통과 여부를 확인한다. 통과 전 24턴·반복 평가를 확장하지 않는다. RAW 내부 규칙 누락을 검증기가 놓치는 문제는 별도 의미 평가로 남는다.

이번 작업에서 제품 모델 계약은 추가 수정하지 않았다. 평가 러너에 실제 case 선택 후속 전송과 미실행 기록을 추가했으며 관련 로컬 테스트 3개가 통과했다. 새 코드의 실제 정확도 향상이나 운영 승격은 아직 주장할 수 없다.
