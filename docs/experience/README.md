# docs/experience

**사람이 결정하고 설계한 것**만 모아 두는 폴더다.

- AI가 제안하거나 대신 정한 것은 여기 적지 않는다. 사람이 AI 제안을 승인만 했다면, "사람의 결정 = 승인·방향"과 "설계 = AI 제안"을 나눠 적는다.
- 매번 쓰지 않는다. 팀원이 요청할 때만 정리한다.
- 형식은 STAR(상황·과제·행동·결과) 등으로 쓴다. 이 프로젝트를 처음 보는 사람도 이해할 수 있어야 한다.
- 팀 안에서만 통하는 약어·코드명(결함 번호, 영역 약칭, 상태 코드, 함수·파일 이름, PR 번호 등)을 쓰지 않는다.
- 파일 이름은 `YYYYMMDD_주제.md`로 한다.

제품·API 계약의 정본은 `docs/dev/`다. 이 폴더는 "왜 그렇게 정했는가"의 기록이며 계약을 대신하지 않는다.
